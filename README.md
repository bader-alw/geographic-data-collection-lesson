## 📖 مقدمة عن الدرس

درس تفاعلي متكامل يغطي جميع جوانب جمع البيانات الجغرافية، من الطرق التقليدية إلى الحديثة، مع التركيز على التطبيقات العملية والأنشطة التفاعلية.

**المعلم:** أ. بدر الوهيبي  
**المستوى:** متوسط وثانوي  
**اللغة:** العربية (RTL)

## ✨ المميزات الرئيسية

### 📚 ثلاثة دروس أساسية:

1. **🗺️ المسح الأرضي**
   - الطرق التقليدية والحديثة
   - الأدوات والمعدات
   - التطبيقات العملية

2. **📡 المسح الجوي والفضائي**
   - تقنيات الأقمار الاصطناعية

   - معلومات عن القمر الصناعي العماني OL-1

3. **🤖 الذكاء الاصطناعي في الجغرافيا**
   - تطبيقات الذكاء الاصطناعي
   - معالجة البيانات
   - التنبؤ والتحليل

- ✅ مقارنة الطرق التقليدية والحديثة

- ✅ نموذج اتصال تفاعلي

## 📊 تتبع التقدم

يمكن تحميل نتائج تقدمك من خلال الدالة `downloadResults()`:

```javascript
// في وحدة تحكم المتصفح (F12)
downloadResults();
```

سيتم تحميل ملف JSON يحتوي على:
- نسبة التقدم الإجمالية
- نتائج الاختبارات
- الأنشطة المكتملة
- معلومات الاتصال
